# Verification Evidence

This directory contains the **canonical**, portfolio-facing evidence generated by:

```bash
make lint
make smoke
make evidence
```

The canonical Verilator run is fixed to:

- all 30 tests;
- random seed `107`;
- 500 randomized APB operations;
- no waveform tracing;
- 4,099 expected scoreboard checks.

Focused tests, coverage waveforms, reduced CI runs, and other ad-hoc parameter sets write under `build/verilator/runs/` and do not overwrite these files.

## GTKWave capture

[`gtkwave-t18-clear-match-collision.png`](gtkwave-t18-clear-match-collision.png) is a focused waveform screenshot showing:

- APB setup and access phases (`PSEL`, `PENABLE`, `PWRITE`);
- register addressing and data (`PADDR`, `PWDATA`, `PRDATA`, `PSTRB`);
- timer control state (`timer_enable_q`, `irq_enable_q`);
- counter and compare state;
- sticky match state and interrupt output.

The screenshot complements, but does not replace, the canonical automated regression, coverage report, and scoreboard log.
